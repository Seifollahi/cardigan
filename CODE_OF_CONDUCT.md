# Code of conduct

## The short version

Be decent. This is a small hobby project about putting barcodes on a
ten-year-old smartwatch — there is nothing here worth being unpleasant over.

## What's expected

- Assume good faith. Most disagreements are missing context, not malice.
- Critique code, not people.
- Remember that maintainers and contributors are doing this in their spare
  time, for free. "This is broken, fix it" is not a great opening.
- Newcomers to embedded C, Pebble, or open source are welcome here. Everyone
  was new once.

## What's not

Harassment, personal attacks, discrimination, sexualised language, sustained
disruption, or publishing others' private information.

## Enforcement

Report problems to the maintainer via the email on their GitHub profile, or
privately via GitHub. Reports stay confidential.

Consequences scale with the behaviour: usually a private word, occasionally
edited or removed comments, rarely a block. The maintainer's decision is
final — this is a small project, not a court.
